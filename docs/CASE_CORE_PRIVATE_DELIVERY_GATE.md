# C.A.S.E. core — offline private delivery eligibility contract

This pure contract is **not wired to production**. It cannot query a database, call Discord, send an alert, publish a finding, generate a case, or punish a player. A test showing `Eligible=true` is a fabricated *all-gates-satisfied fixture*, **not proof** that any deployed detector or current Champions evidence is eligible.

It formalizes requirements before a future private CASE_ALERTS sender is reviewed: exact positive guild/installation/server scope, evidence and route scope match, immutable opaque finding/version/reference, independent staff review, source and evidence-quality acceptance, independently validated detector, reviewer authorization, an accessible evidence view, owner-enabled staff notification, reachable private route and enforcement disabled. Any missing flag or scope mismatch produces blocker codes and no delivery key; a source ref with raw path syntax is rejected. Deterministic idempotency key incorporates tenant, installation, server, opaque finding and revision; the resulting key is hashed.

**Still missing:** a durable case store, independent authenticated staff authorization, reviewed live detector and evidence admission, private destination ACL recheck, durable outbox with idempotent enqueue/lease/retries and terminal states, mention-safe embed rendering, subscriber entitlement, production flag, actual sends, audits and rollback. Every claim is rechecked inside a future transaction and before delivery, not trusted from a caller's booleans. No `CASE-MOV-001` movement activation or real publisher is authorized. Real-source acceptance #114 remains open; master roadmap #124 governs release.
