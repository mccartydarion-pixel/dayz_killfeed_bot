# C.A.S.E. Gate A — bounded retained source inspection (offline)

This repository candidate addresses the specific gap in #114: the existing ADM poller parsed 75 events in the newly selected Champions file, but those runtime counts are **not** proof that an allowlisted C.A.S.E. evidence row was retained for the same boot. It creates no additional ADM polling and does not inspect production data.

`CurrentSourceEvidenceInspector.Inspect` takes an **internal canonical source identity from the trusted existing worker**, positive guild/server IDs and a 1–200 bound. A read-only repeatable-read transaction fetches the latest retained source record overall and up to `limit+1` retained rows matching the selected identity under that exact scope. Results contain only pseudonymous source references, bounded row count/truncation, latest offsets and ingestion timestamps; no raw source path, player identity, ADM line, coordinates or detector inference. It can show that a selected source has old rows even when the **latest** record is another boot. The test uses a disposable database and verifies that historical rows are not promoted, cross-server rows cannot leak, empty scopes are explicit, and malformed bounds fail closed.

This method currently has **no application, HTTP or production caller**. A future protected endpoint may combine it with synchronized worker source-health metadata and selected/accepted source identity only after a separately approved, reviewed production change. Those snapshots remain non-atomic; a positive result is an observation for authenticated human review, not Gate A PASS by itself. The selected-source pseudonym and latest retained pseudonym should be compared with the existing protected integrity response. Ingestion timestamp must not be interpreted as gameplay event time; a bounded row page cannot establish unfiltered ADM completeness.

#114 remains open until the actual authenticated Champions staff capture verifies selected=accepted=latest retained source for the precise installation/server, retained offset/time, collector state and source-quality limitations. Do not fetch secrets, start a second poller or copy raw player/source data into issues. No detector, case writer, sender or enforcement activation is in this change.
