# C.A.S.E. exact blocked shadow readback

The offline Gate C diagnostic ledger may need to verify an exact prior BLOCKED evaluation after more than 50 newer records exist. `GetShadowHistoryByID` reads by positive guild, server and evaluation ID and returns the same neutral metadata as the bounded history page. A foreign scope yields no record. It has no new HTTP route or runtime caller.

The disposable PostgreSQL regression inserts 51 newer synthetic diagnostics, proves that the first record has left the newest 50, then reads it by exact ID and rejects foreign guild/server lookups. No evaluator, one-shot CLI, source polling, case producer, staff sender or enforcement is activated. This is readback plumbing only; real current-source acceptance and detector validity remain separate gates.
