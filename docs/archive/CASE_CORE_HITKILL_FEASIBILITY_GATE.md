# C.A.S.E. gate B — retained hit/kill source-quality audit only

The existing console collector retains selected hit and kill event lines, but event visibility is not cheating detection. This offline, uncalled pure audit reuses the bounded evidence-source admissibility contract. It counts selected hit, kill and contextual observations, distinct ADM sources, malformed addresses/clocks and bounded page edges. It deliberately contains **no identity, hit-rate percentage, score, threshold, accusation, finding, case write, Discord publisher or enforcement**. A large hit count cannot lift NOT_VALIDATED.

## Independent validation needed before any first detector

1. Verify a normal current-source retained record in the existing protected staff view for the exact installation/server (#114); preserve source, offset, hash and quality provenance without publishing identities.
2. Establish what PlayStation ADM emits under controlled, consensual legitimate combat. Document filtered-event omissions, actor/target semantics, time ambiguity, missing weapon/damage fields, and source rotations.
3. Define a concrete observable hypothesis and disconfirming legitimate counterexamples before proposing any cheating classification. Assess ordinary high-skill play, repeated hits, explosive damage, repeated log emission and bounded-window artifacts; never treat count alone as a verdict.
4. Test on isolated fixtures, then obtain separate approval for staff-only real-source shadow observation. Measure unverified evidence and independent false-positive review against a clearly defined population. If no valid source supports it, leave detector unsupported.
5. Keep CASE-MOV-001 BLOCKED with safe speed pairs zero. A source with 75 parsed events is not 75 admissible evidence rows, high-resolution gameplay time or continuous position telemetry.

This branch adds no runtime caller, database query/migration, Nitrado poller, staff endpoint, route, alert or sanction. It is an isolated tool for reviewing whether any first detector is feasible. Gate B, live alerts and case admission remain closed.
